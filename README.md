# Changes I made in this Version

As a side project I made some changes that bothered me as a kid in the original version. 

## Pokémon Evolutions

- There are no more trade Evolutions in the Game. All the Trade Evolutions (Alakazam, Gengar etc.) have been replaced by level up Evolutions at Level 36.
- Feebas evolves into Milotic at Level 30, independent of its "Beauty".
- Trade Item Evolutions have been replaced:
    - Poliwhirl evolves into Politoed by using a Leaf Stone.
    - Slowpoke evolves into Slowking by using a Water Stone.
    - Onix evolves into Steelix at Level 36.
    - Seadrda evolves into Seadraking by Level 36. (Horsea now evolves into Seadra at 25).
    - Scyther evolves into Scissor at Level 36.
    - Porygon evolves into Porygon2 at Level 32.
    - Clamperl evolves into Huntail by using a Water Stone.
    - Clamperl evolves into Gorebyss by using a Moon Stone.

## Pokémon Encounter 

- Feebas encounter has been changed to be available at each Tile on Route 119 with a 50% chance.
